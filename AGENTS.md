# Правила документации и выпусков

- Изменения по версиям записывать только в CHANGELOG.md. Для каждого опубликованного релиза нужна отдельная запись, восстановленная по истории Git и содержимому релиза.
- README описывает текущее состояние, установку и использование; скриншоты и историю изменений в него не добавлять.
- RELEASE.md и описания GitHub Releases содержат ссылки на CHANGELOG.md и инструкции по установке без дублирования изменений.
- Перед выпуском применять навык pre-release-check. Проверять установку готового client.zip через ApplyPack лаунчера, включая сохранение пользовательских настроек; успешная упаковка не подтверждает работоспособность установки.
- Сохранять пользовательские настройки и оформление FancyMenu / Drippy Loading Screen. В коммиты включать только изменения текущей задачи; после проверки коммитить через подключённый GitHub-плагин.
