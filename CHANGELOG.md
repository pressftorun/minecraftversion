# Изменения клиентской сборки

## 2026-10-28

- Для обновления списка модов публикуется отдельный `optional-mods.zip` около 9 МБ с манифестом и SHA-256; полный клиент сохраняется отдельно.
- Craft Config Library 1.1.12 для NeoForge 1.21.1 добавлена в обязательные моды.

- Quick Skin 3.1.1 (NeoForge, Minecraft 1.21.1) добавлен в опциональные моды: выключен по умолчанию, включается в разделе «Клиентские моды» лаунчера.
- Добавлена обязательная для Quick Skin библиотека Architectury API 13.0.11 в основной состав клиента.

## 2026-10-22

- Voxy выключен по умолчанию: отключены мод, рендеринг и приём данных.

- Восстановлены все настройки клиента до синхронизации, включая options.txt и полный config; сохранены 62 эталонных мода.

- Восстановлены настройки оформления FancyMenu и Drippy Loading Screen после синхронизации модов.

- Пакет синхронизирован с локальной сборкой «минимум»: 62 мода, добавлены Forgified Fabric API, Roxy, Voxy, Voxy Server Side и Zume.
- Обновлены клиентские настройки; пользовательские миры, аккаунты и журналы не включены.

- Из клиентского пакета удалён NeoLogin 1.1.2: серверный мод блокировал взаимодействие с блоками на клиенте.
- Упаковка отклоняет случайное добавление NeoLogin в клиентские моды.
- Обновление доступно через «Проверить файлы» в лаунчере; серверный NeoLogin сохраняется.

## Начальная сборка

- Minecraft 1.21.1 и NeoForge 21.1.264.
- Моды Create и дополнения, клиентские настройки, меню и экран загрузки проекта.
