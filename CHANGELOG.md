# Изменения клиентской сборки

Каждая запись соответствует опубликованному тегу GitHub Releases. Даты указаны по Екатеринбургу (UTC+5); записи восстановлены по истории Git и опубликованным релизам.

## Следующий релиз

- Исправлена ошибка «Недопустимый путь пакета: VISUAL-PACKS.md», блокировавшая установку клиента.
- Сведения об авторах и лицензиях перенесены в разрешённый путь `resourcepacks/VISUAL-PACKS.md`.
- Упаковка отклоняет пути, не поддерживаемые лаунчером; добавлена регрессионная проверка запрещённого файла в корне.
- Исправленный архив проверен реальным `LauncherService.ApplyPack`: чистая установка и повторное обновление устанавливают все четыре визуальных пакета и сохраняют пользовательские настройки и оформление. Встроенные тесты лаунчера и тесты упаковки прошли; графический запуск новых пакетов отдельно не проверялся.
