Сборка синхронизирована с локальным эталоном «минимум»: добавлены Forgified Fabric API, Roxy, Voxy, Voxy Server Side и Zume, обновлены клиентские настройки.

Клиент для **Minecraft 1.21.1 · NeoForge 21.1.264**, 62 мода.

### Исправлено разрушение блоков на сервере

Из клиентской сборки удалён NeoLogin 1.1.2. Он предназначен для выделенного сервера; на клиенте его обработчики отменяли клики по блокам и другие взаимодействия, даже если игрок успешно выполнил `/login` на сервере.

Серверный NeoLogin удалять не нужно. Авторизация на сервере продолжает работать.

### Как обновить

1. Закройте Minecraft.
2. В [Create Launcher](https://github.com/pressftorun/minecraftlauncher/releases/latest) нажмите **«Проверить файлы»**.
3. Дождитесь обновления, запустите игру и войдите на сервер через `/login`.

Лаунчер скачает новый архив, проверит SHA-256 и удалит прежний NeoLogin из файлов пакета. Переустановка лаунчера не требуется.

Для ручной установки доступны `client.zip` и `client.zip.sha256`. Minecraft, Java, миры, аккаунты и журналы в архив не входят. Лицензии модов сохраняются; см. [NOTICE.md](https://github.com/pressftorun/minecraftversion/blob/main/NOTICE.md).
