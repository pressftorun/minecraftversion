### Выравнивание главного меню

Исправлены перекрытия кнопок при изменении размера окна и масштаба интерфейса. Строка «Настройки / Моды» выровнена по краям остальных кнопок, сохранены одинаковые промежутки между строками. Моды, фон, экран загрузки и пользовательские настройки не заменяются.

### Быстрое обновление списка и обязательная библиотека

- Для Create Launcher 0.3.6 и новее публикуется небольшой `optional-mods.zip` вместо скачивания всего клиента при обновлении списка модов.
- Craft Config Library 1.1.12 для NeoForge 1.21.1 включена в обязательные моды. Установите её через «Проверить файлы».
- Для ручной установки используйте полный `client.zip`; архив `optional-mods.zip` содержит только опциональные моды и не заменяет установку клиента.

### Опциональный Quick Skin

Добавлен Quick Skin 3.1.1 для Minecraft 1.21.1 / NeoForge. Обновите список в разделе «Клиентские моды» лаунчера и включите Quick Skin; изменение применится при следующем запуске игры. По умолчанию мод выключен. Необходимая библиотека Architectury API 13.0.11 устанавливается вместе с клиентом; перед первым включением Quick Skin нажмите «Проверить файлы».

Сборка синхронизирована с локальным эталоном «минимум»: добавлены Forgified Fabric API, Roxy, Voxy, Voxy Server Side и Zume, обновлены клиентские настройки.

Клиент для **Minecraft 1.21.1 · NeoForge 21.1.264**, основные и опциональные моды.

### Исправлено разрушение блоков на сервере

Из клиентской сборки удалён NeoLogin 1.1.2. Он предназначен для выделенного сервера; на клиенте его обработчики отменяли клики по блокам и другие взаимодействия, даже если игрок успешно выполнил `/login` на сервере.

Серверный NeoLogin удалять не нужно. Авторизация на сервере продолжает работать.

### Как обновить

1. Закройте Minecraft.
2. В [Create Launcher](https://github.com/pressftorun/minecraftlauncher/releases/latest) нажмите **«Проверить файлы»**.
3. Дождитесь обновления, запустите игру и войдите на сервер через `/login`.

Лаунчер скачает новый архив, проверит SHA-256 и удалит прежний NeoLogin из файлов пакета. Переустановка лаунчера не требуется.

Для ручной установки доступны `client.zip` и `client.zip.sha256`. Minecraft, Java, миры, аккаунты и журналы в архив не входят. Лицензии модов сохраняются; см. [NOTICE.md](https://github.com/pressftorun/minecraftversion/blob/main/NOTICE.md).
