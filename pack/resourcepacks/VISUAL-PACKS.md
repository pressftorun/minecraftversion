Faithful is an independent project and does not endorse this client. Its resource packs are optional visual choices: enable one resolution in Minecraft's Resource Packs menu. Select one shader in Iris's Shader Packs menu. Complementary Reimagined remains the default for a fresh installation; existing player settings are preserved on update.
